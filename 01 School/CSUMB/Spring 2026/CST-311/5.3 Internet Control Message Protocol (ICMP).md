# ICMP: Internet Control Message Protocol
- Used by hosts and routers to communicate **network-level information**
	- ICMP messages carried in IP datagrams
	- Do not contain Transport Layer payload
- Error reporting: unreachable host, network, port, protocol
- Echo request/reply (used by ping)
- Network diagnostics and control messages

- Has type, code, plus first 8 bytes of IP datagram causing error

# Traceroute with ICMP
- Source sends sets of UDP segments to destination
	- 1st set has TTL = 1
	- 2nd set has TTL = 2
	- 3rd set has TTL = 3
	- ...
- If the TTL reaches 0, the router returns an ICMP message (TTL-exceeded - type 11, code 0) to the sending host
	- Datagram in nth set arrives to nth router
- The datagram with a TTL of 1 will cause the router one hop away from the sender to send an ICMP TTL-exceeded message back to the sender
![[Pasted image 20260504144527.png|350]]
- The datagram sent with a TTL of 2 will cause the router two hops away to send an ICMP message back to the sender
![[Pasted image 20260504144745.png|350]]
- The datagram sent with a TTL of 3 will cause the router three hops away to send an ICMP message back to the sender
![[Pasted image 20260504144827.png|350]]
- The source can learn the IP addresses of the routers between itself and the destination by looking at the source IP addresses in the datagrams containing the ICMP TTL-exceeded messages
## When To Stop
- UDP segments eventually arrives at destination host
- Destination returns ICMP "port unreachable") message (type 3, code 3)
- Source stops
